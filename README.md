# Professional audio on the Web, what now?

Slides for my talk “Professional audio on the Web, what now?” given on the 2026-10-29 in Cannes, France for the IEEE International Symposium on the Internet of Sounds (IS2) 2026.

https://internetofsounds2026.ieee-internetofsounds.org/

## View the slides

Open `index.html` in a modern browser. The presentation uses Remark.js, with chart code in `charts.js` and supporting data and images in `assets/`. Internet access may be needed for chart dependencies loaded by the presentation.

## `remark.js`

https://github.com/remarkjs/remark, MIT
